## Metodología de Clasificación

La clasificación se realizó mediante el script `scripts/clasificar-arquetipos-flora.mjs` que:

1. **Lee el catálogo fuente** `chagra-catalog-oss-subset-v3.2.json`
2. **Analiza para cada especie:**
   - Categoría agronómica (frutales, hortalizas, arbustos, etc.)
   - Familia botánica
   - Campo `habito_raw` cuando disponible
   - Campo `estrato_raw` cuando disponible
3. **Asigna arquetipo** basado en reglas determinísticas
4. **Asigna confianza:**
   - `alta`: cuando hay datos de hábito explícitos
   - `baja`: cuando se infiere desde categoría/familia
   - `revisar`: cuando no hay datos suficientes
5. **Registra razón** de la clasificación para transparencia
