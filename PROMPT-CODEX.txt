## Qué es
Un "oráculo de territorio" que unifica coordenadas geográficas con descriptores de zona, para dar
contexto de lugar a la app Chagra (multi-finca, GPS-aware). Puro cómputo geoespacial.

## API (archivo `oraculo.mjs`, exporta funciones puras)
1. `encodePlusCode(lat, lng, codeLength=10)` → string — implementá **Open Location Code (Plus Codes)**
   desde cero (algoritmo público de Google, base-20 alfabeto `23456789CFGHJMPQRVWX`). Sin librerías.
2. `decodePlusCode(code)` → `{ latCenter, lngCenter, latLo, lngLo, latHi, lngHi }`.
3. `haversine(a, b)` → metros — distancia gran-círculo entre `{lat,lng}`.
4. `bearing(a, b)` → grados 0–360 — rumbo inicial de a→b.
5. `pointInPolygon(point, ring)` → bool — ray-casting puro sobre un anillo `[[lng,lat],...]`.
6. `zonaDe(point, geojson)` → `{ zonaId, nombre } | null` — recorre features Polygon de un GeoJSON
   (pasado como argumento, NUNCA hardcodeado) y devuelve la primera zona que contiene el punto.
7. `oraculo(point, { geojson, referencias })` → objeto unificado:
   `{ plusCode, zona, referencias: [{ id, nombre, distanciaM, rumbo }] ordenadas por distancia }`.
   `referencias` = lista de puntos de interés `{id,nombre,lat,lng}` pasada como argumento.
